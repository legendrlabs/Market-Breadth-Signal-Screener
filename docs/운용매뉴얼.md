# MBSS v0.1.2 한국어 운용 매뉴얼

## 1. 용도

MBSS는 시장 상승 참여도와 전술 유동성 판단을 보조하는 독립 연구 계층입니다. 장기 주식모으기, 인컴 ETF 분배금의 TQQQ 재투자, Mechanical Top15·K-Mechanical의 별도 운용은 유지합니다. 현금 20% 의무를 도입하지 않으며 추격매수나 신호 하나로 전액투입을 지시하지 않습니다. 실제 비중은 별도의 백테스트·위험예산 검증 이후 승인 대상입니다.

## 2. 상태 읽기

| 상태 | 뜻 | 운용 |
|---|---|---|
| DATA_HOLD | 입력·정의·거래일 검증 부족 | 투입 판단에 사용하지 않음 |
| NO_SIGNAL | 유효 입력에서 신규 신호 없음 | 장기 원칙 유지 |
| WATCH | A 저점 후 10일 내 진행 / B 1~2일 / C 4~5일 충족 | 다음 종가 관측 |
| CONFIRMED | 해당 완료 거래일에 조건 충족 | 위험과 검증 상태 확인; 자동매수 아님 |
| HISTORICAL_SIGNAL | 최근 과거 신호 추적 중 | A/B/C 기본 20거래일 관찰; D는 선거 후 6개월 |
| EXPIRED | 관찰기간 종료 | 과거 통계로만 보관 |

현재 버전의 SAFE_TO_ACT는 항상 False입니다. 코드·데이터·위험예산 검증이 완료되기 전 True를 출력하지 않도록 고정합니다. CONFIDENCE는 근거 완성도를 뜻하며 미래 승률이 아닙니다. 정상 동작과 실전 사용 가능은 다른 판정입니다.

## 3. 일일 점검

1. `collect` 이후 `run`을 실행합니다. 보고서의 실행시각과 완료 NYSE 거래일을 확인합니다. 미국 종가가 나오기 전 한국 저녁 실행은 직전 미국 거래일을 사용합니다.
2. `data_quality.json`의 source, start/end, history_valid, freshness, flags를 확인합니다. 다운로드 성공을 품질 통과로 해석하지 않습니다.
3. Breadth universe가 불명확하면 A/C는 DATA_HOLD입니다. SPX 가격만으로 Breadth를 추정하지 않습니다.
4. `signal_events.json`에서 필수 8개 필드와 신호별 상태를 확인합니다. 한 신호가 유효하더라도 전체 입력 부족은 전체 DATA_HOLD로 표시할 수 있습니다.
5. VIX >=30, 5거래일 +25% 이상 상승, SMA200 아래, 252일 고점 대비 -15% 아래, 상승종목 비율 <50%, 최근 신호 이후 -5% 재하락은 설명용 위험 플래그입니다. 임계값의 실전 효과를 검증했다고 주장하지 않습니다.

## 4. 백테스트 해석

수익률은 실제 다음 시가 진입 기준입니다. 표본 수는 성숙한 보유기간만 집계합니다. 청산 목표일이 아직 오지 않았으면 IMMATURE이며, 최근 종가로 대신 청산해 승률에 넣지 않습니다. 휴장일은 다음 거래일로 이월합니다. max_drawdown은 일별 종가 기준이며 max_upside/max_adverse_excursion은 고가/저가 기준입니다. 이벤트의 경로 위험 수치는 비용 전 가격 경로이고, 순수익률과 전략 자산곡선에는 입력 비용을 적용합니다.

복합 신호는 마지막 구성 신호가 확인된 날만 확정합니다. A/B/C의 5거래일·10거래일 결합과 D의 선거 이후 6개월 구간 내 결합을 연구합니다. 사건 통계와 연속 운용전략은 구분합니다. 보유기간이 겹치는 사건은 연결 군집으로 묶어 부트스트랩하며, 표본을 독립적 성공 횟수로 과장하지 않습니다. 윌슨 구간은 참고용이고 군집 의존성을 해결한 승률 검정이 아닙니다.

SPY 전략 비교는 비교 가능한 입력들의 공통 기간을 사용합니다. 신호가 없으면 현금 0% 이자로 대기하고, 한 번 진입하면 6/12개월 후 청산하며 보유 중 추가 신호는 무시합니다. 관측되지 않은 과거 구간을 신호 없는 대기로 간주하지 않습니다. 개별 사건의 QQQ 초과수익률, 전기간 SPY 전략의 성과는 질문이 다릅니다.

모든 100% 승률 표본과 복합 조건은 작은 표본·겹침·다중검정·정의 수정·공급원 수정의 영향을 받습니다. 이 버전은 p-value나 미래 승률을 제시하지 않습니다. 성과가 좋게 보이는 조건만 선택하여 운용 규칙으로 승격하지 않습니다.

## 5. 재현과 장애

같은 입력 파일·패키지 버전·설정·as-of·seed를 사용합니다. 데이터 조회 시점이 바뀌면 공급원 과거값이 수정될 수 있으므로 새 실행 폴더를 만듭니다. manifest의 input/output SHA256과 환경 버전을 보존합니다. 데이터 재배포 가능 여부는 공급원별로 확인합니다.

거래일 의존성 설치 실패: 정상 온라인 환경에서 `python -m pip install -e .` 후 테스트합니다. 가격 다운로드 실패: 오류·원자료 해시를 확인하고, 유효한 CSV와 정확한 메타데이터를 입력합니다. NYSE Breadth 부족: 범위가 비교 가능한 합법적 공개 자료를 확보하기 전 DATA_HOLD를 유지합니다. 결과값에 맞추어 날짜·티커 예외를 추가하지 않습니다.
